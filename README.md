# 두루고등학교 교육과정 안내

두루고등학교 2022 개정 교육과정 수강신청 가이드 웹사이트입니다.
입학년도(2025, 2026)에 따라 맞춤형 교육과정 정보 및 수강신청 가이드를 제공합니다.

## 🚀 실행 방법

이 프로젝트는 Google Sheets에서 실시간으로 데이터를 가져오므로 **로컬 웹 서버**를 통해 실행해야 정상적으로 작동합니다.

### 방법 1: Python 사용 (가장 간단)

터미널을 열고 프로젝트 폴더로 이동한 후 아래 명령어를 실행하세요.

```bash
# Python 3.x 이상
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 에 접속합니다.

## 📂 파일 구조

- `index.html`: 메인 페이지 구조 (연도 선택 랜딩 페이지 포함)
- `script.js`: 데이터 처리 및 동적 렌더링 로직 (PapaParse 라이브러리 활용)
- `style.css`: 글래스모피즘 기반 다크 모드 스타일
- `logo.png`: 두루고등학교 로고

## 📊 데이터 연동 안내

이 사이트는 **구글 스프레드시트**의 데이터를 CSV 형태로 실시간 연동합니다.
데이터 수정이 필요할 경우 `script.js` 상단의 `CSV_URLS` 객체에 있는 링크의 원본 스프레드시트를 수정한 후 웹에 게시(CSV)하면 자동으로 반영됩니다.

- 2025학년도 입학생: `script.js` 내 `CSV_URLS[2025]`
- 2026학년도 입학생: `script.js` 내 `CSV_URLS[2026]`
